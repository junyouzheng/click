# click

click 同时管鼠标和键盘。点击鼠标时，在指针位置播放星火和手机键盘声。滑动鼠标时拖出一条会淡掉的浅蓝色光尾。箭头仍是系统箭头的形状，只在箭身上加了一小段蓝色，退出程序后恢复系统箭头。

左键、右键、中键都是手机键盘的轻点，音高略有不同，颜色分别是金色、蓝色、绿色。敲键盘也是这个声音，按下是指尖点在屏幕上，松开是很轻的抬起。退格键单独用更低、更闷的删除声。键盘声可以单独关掉。声音大小跟系统音量走，程序里不再单独调节。

需要 Windows，以及 .NET 8 桌面运行时。程序按当前用户身份运行，不请求管理员权限。

```powershell
dotnet publish -c Release -r win-x64 --self-contained false -o dist
```

发布后的程序是 `dist\click.exe`。窗口上没有关闭按钮，打开后贴在工作区右下角，离右边和底边 4 像素。左键点击托盘图标可以打开，再点一次收回。点到窗口外面也会收回托盘。右键只有开机自启动和退出，光效和声音都在窗口里设置。

开机自启动用当前用户的 Run 项，启动参数是 `--background`。登录时静默启动，不弹出窗口，也不提示错误，只留在托盘。

从管理员身份的窗口里点击或打字时，Windows 不会把这次输入交给普通权限的程序。那种窗口要有特效和声音，需要这个程序也以管理员身份运行。
